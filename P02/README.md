# Modul 2 — Website Portofolio (HTML Murni)

Pembuatan website portofolio pribadi menggunakan **HTML saja** (tanpa CSS dan JavaScript).

## Halaman

`index.html` · `about.html` · `skill.html` · `educational.html` ·
`experience.html` · `project.html` · `resume.html` · `kontak.html`

## Konvensi

- Semua halaman memakai `<header>` (judul + navigasi), `<main>` berisi `<section>`/`<article>`,
  dan `<footer>`, dipisahkan oleh `<hr>`.
- Navigasi konsisten di semua halaman dan menunjuk ke file lain di folder yang sama.
- Bahasa dokumen: `lang="id"`.
- Ukuran `<title>` Format: `Portofolio Mahasiswa — <Nama Halaman>`.

## Catatan

Modul 3 (`../P03/`) memakai konten HTML yang sama persis dan menambahkan
`style.css` sebagai pemisah.
